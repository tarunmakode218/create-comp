# 🚀 create-comp

> ⚡ Generate clean and ready-to-use React components in seconds with zero manual setup.

---

## 🎯 Why this tool?

While building React apps, developers often spend time on repetitive tasks like:

- Writing the same component structure again and again  
- Manually setting up styling (CSS or Tailwind)  
- Creating basic UI layouts from scratch  

👉 Most existing tools only solve part of the problem:
- They generate very basic files  
- No automatic styling decisions  
- No real-world UI patterns  
- Limited developer experience  

---

## 💡 What create-comp does

**create-comp** is a CLI tool designed to speed up development by:

- 🧠 Automatically detecting if your project uses Tailwind  
- ⚡ Instantly generating React components  
- 🎨 Providing pre-designed UI templates (Card, Navbar, Button)  
- 🔥 Supporting modern setups like Vite, CRA, and Next.js  

---

## 🚀 Key Features

- ✅ Smart Tailwind detection  
- ✅ Supports both CSS and Tailwind  
- ✅ Built-in component templates  
- ✅ Automatic PascalCase naming  
- ✅ Prevents duplicate component creation  
- ✅ Works directly with `npx` (no install required)  

---
